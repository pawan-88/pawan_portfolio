## Connect GitHub (required for auto-deploy)

If the live site shows old content, connect your repo:

1. Open the [Vercel project dashboard](https://vercel.com/pawan-sanaps-projects-42889b10/pawan-portfolio)
2. Go to **Settings → Git**
3. Click **Connect Git Repository**
4. Select **`pawan-88/pawan_portfolio`**
5. Branch: **`main`** · Framework: **Next.js**
6. Click **Redeploy** on the latest deployment

After connecting, every `git push` to `main` auto-deploys.

## Manual redeploy

From the [Deployments](https://vercel.com/pawan-sanaps-projects-42889b10/pawan-portfolio) tab → **Redeploy** → Production.
