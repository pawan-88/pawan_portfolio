# Premium Developer Portfolio

Modern Next.js portfolio inspired by [aadityapadiya.vercel.app](https://aadityapadiya.vercel.app/).

## Quick Start

```bash
npm install
npm run dev
```

See **[PORTFOLIO.md](./PORTFOLIO.md)** for full documentation, customization, and Vercel deployment.

## Legacy Static Site

The original TemplateMo HTML portfolio files (`index.html`, `css/`, `js/`) remain in the repo root. The Next.js app runs from `app/` when you use `npm run dev`.
